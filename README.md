A program that paints a travel poster for **SOLMARA** — a white cliff town
above a teal sea where the sun sets twice — to `/output/entry.png`.

SOLMARA does not exist. Its two suns, its lighthouse and its little warm-lit
houses do not either. The poster is drawn entirely in code: Python 3.13
standard library only, no network, no third-party packages, with a hand-rolled
PNG encoder and a bitmap font drawn by the program itself.

## Run it

```sh
python3 main.py
```
